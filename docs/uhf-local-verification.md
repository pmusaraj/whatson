# Local UHF verification — 2026-09-15

Tested the installed UHF 1.97.0 app and its existing Estv playlist on macOS.

## Evidence

The local HTTP server recorded UHF fetching `/data/uhf/epg-stable.xml` successfully after reopening the app. The app then wrote a new parsed EPG cache. The read-only `scripts/audit_uhf_epg.py` check joined the actual playlist selections and name aliases against that cache:

| Playlist category | Total rows | Before: rows with schedules | After: rows with schedules | After: next 24 hours |
| --- | ---: | ---: | ---: | ---: |
| Canada | 147 | 84 | 86 | 86 |
| Spain | 108 | 2 | 48 | 48 |

After the priority-channel reload, the imported cache had current programmes for 80 Canadian and 48 Spanish rows. All five TSN rows and 15 of 17 Movistar rows had current listings and next-day coverage. These are source listings; this test did not compare them with video playback.

With Accessibility enabled, UHF's displayed search results confirmed TSN 1/3 (`Big Day With Peter Schrager`), TSN 2 (`SC`), and TSN 4/5 (`NASCAR Canada Series`). Its home guide showed the main Movistar LaLiga feed's Elche–Real Madrid pre-match, match, and post-match listings. Movistar search results also showed current programmes for Golf, Deportes, Liga de Campeones, Acción, Drama, Comedia, Estrenos, Cine Ñ, Cocina, Decasa, Series, and the numbered LaLiga feeds. These checks used the app's accessibility text, not only the exported XML. The parsed cache was generated by UHF itself, not injected by the test.

The UI check caught a limitation of the cache audit: UHF's automatic matching showed the main LaLiga row with an overflow feed's programme despite the exact alias in the cache. Explicit provider/channel assignments fixed the displayed result. The audit proves available data and exact saved references; automatic matches still need a UI check.

## Fixes tested

- Fetch Orange's shared eight-hour segments once per date/segment, with retries. The previous per-channel grabber produced socket failures and exceeded the source-wide timeout before saving its results.
- Generate stable source IDs while preserving the original `uhf:<pk>` export. Merge playlist-name aliases for duplicate variants.
- Honor UHF's explicitly selected CBC Fredericton guide instead of overriding it with the old Toronto name.
- Map the four Movistar LaLiga rows to their distinct feeds rather than LaLiga's studio channel.
- Add explicit TSN 1–5 and 15 Movistar EPG assignments in the local Estv playlist to avoid ambiguous automatic matching.
- Fetch 12 Movistar feeds from the [official daily schedules](https://www.movistarplus.es/programacion-tv/golf+/2026-09-15), with Madrid timezone handling and following-programme end boundaries. The test fetched 48 pages and produced 487 programmes before the export's duration filter. Cocina, Decasa, and Series use their other mapped sources.
- Give larger Canadian source batches a proportional timeout.
- Schedule UHF refreshes every 12 hours so the three-date guide window does not expire between builds.
- Add a country filter for focused refreshes and a read-only local cache audit.

Verification passed 61 unit tests; the generated XMLTV validator reported zero structural errors. Remaining warnings concern upstream gaps, overlaps, and placeholder listings.

The local test retained France, UK, and US schedules from the published feed downloaded earlier that day. Those temporary source snapshots are ignored by Git. Production has not been deployed. After deploying, switch Estv to `https://heywhatson.tv/data/uhf/epg-stable.xml` and refresh its EPG.
